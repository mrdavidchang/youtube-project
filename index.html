This is a live demo website of my full stack Javascript web application.
Inspired by my desire to binge watch Youtube channels faster.
It utilizes HTML, CSS, Javascript, Youtube Data API v3, Chart.js, and jQuery.

Currently the website is on a 10,000 quota/data limit (which is very very little).
If the website is down it's most likely because all the quota have been used and will be reset at midnight.
I emailed and submitted a quota increase request form to Youtube, so hopefully I will get a response.
